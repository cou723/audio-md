# 機能要件

## 実装する機能（最低限）

1. エディタタイトルバーのボタン押下時、テキストエディタの右隣に Webview パネルを起動する（テキストエディタは残す）
2. 左カラム（モノラル160px、ステレオは L・R を並べて320px）：音声スペクトログラムを縦描画（Y軸＝時間、X軸＝周波数・対数軸、色＝強さ）
3. 右カラム（残り全幅）：ブロックテキストをMarkdownとしてレンダリングし、スペクトログラムと対応するY位置に表示
4. ツールバー：再生・一時停止、現在時刻 / 総時間の表示
5. スペクトログラム左クリック/ドラッグ → 離した位置にシーク（再生中はそこから継続、停止中はプレイヘッド移動のみ）
6. スペクトログラム右クリック → エディタのカーソル位置にポイントタイムスタンプ構文を挿入
   スペクトログラム右ドラッグ → 範囲タイムスタンプ構文をエディタに挿入
7. 左右カラムのスクロール同期
8. 再生中はスペクトログラムを自動スクロールしてプレイヘッドを追う
9. Webview console.log をlogファイルへ書き出す（デバッグ用）
10. ノートブロッククリック → そのブロックの開始時間にシーク
11. ツールバーの音量スライダーを放したとき、`audio-md.volume` をユーザー設定（`ConfigurationTarget.Global`）に保存し、プレビュー起動時と設定変更時に復元・反映する。`workbench.settings.applyToAllProfiles` に含まれるキーの書き込み先は VS Code が default プロファイルに振り分けるため、拡張側で分岐しない

## 実装しない機能

- Webviewでのノート編集（読み取り専用）
- ファイルの自動保存（VSCodeの手動保存のみ）
- バリデーション（ファイルサイズ・フォーマット検証不要）

具体的なUI・スペクトログラム描画の実装仕様は [webview-ui.md](./webview-ui.md) を参照。
