# 機能要件

## 実装する機能（最低限）

1. エディタタイトルバーのボタン押下時、テキストエディタの右隣に Webview パネルを起動する（テキストエディタは残す）
2. 左カラム（160px固定）：音声波形を縦描画（Y軸＝時間）
3. 右カラム（残り全幅）：ブロックテキストをMarkdownとしてレンダリングし、波形と対応するY位置に表示
4. ツールバー：再生・一時停止、現在時刻 / 総時間の表示
5. 波形左クリック/ドラッグ → 離した位置にシーク（再生中はそこから継続、停止中はプレイヘッド移動のみ）
6. 波形右クリック → エディタのカーソル位置にポイントタイムスタンプ構文を挿入
   波形右ドラッグ → 範囲タイムスタンプ構文をエディタに挿入
7. 左右カラムのスクロール同期
8. 再生中は波形を自動スクロールしてプレイヘッドを追う
9. Webview console.log をlogファイルへ書き出す（デバッグ用）
10. ノートブロッククリック → そのブロックの開始時間にシーク

## 実装しない機能

- Webviewでのノート編集（読み取り専用）
- ファイルの自動保存（VSCodeの手動保存のみ）
- バリデーション（ファイルサイズ・フォーマット検証不要）

具体的なUI・波形描画の実装仕様は [webview-ui.md](./webview-ui.md) を参照。
